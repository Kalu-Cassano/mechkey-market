# Data dictionary

| Bảng | Trách nhiệm |
|---|---|
| users | Tài khoản và vai trò customer/vendor/admin |
| categories | Danh mục dùng chung |
| products | Sản phẩm thuộc một vendor và category |
| orders | Thông tin tổng quát của đơn hàng |
| order_items | Sản phẩm, người bán, giá và số lượng tại thời điểm mua |
| payments | Phương thức, trạng thái và mã giao dịch của đơn hàng |
| reviews | Một đánh giá cho mỗi người mua trên mỗi sản phẩm |
